# frenchbloke

Browser-based audio experiments. Single HTML files — right-click, save as, use anywhere.

Landing page: https://frenchbloke.github.io

## Projects
- **[HAMSTRAD](https://frenchbloke.github.io/hamstrad/)** —  This looks at an audio track really hard.  
It then looks at another and makes the foolish decision to try and make the first one into the second one by chopping it all up and gluing it back together. 
- **[glue](https://frenchbloke.github.io/glue/)** — After weeks of disassembling audio files with some rate of precision, what if you could load a MIDI file and use the sliced beats to play that MIDI file? Tested with Blue Monday (you can import other MIDI files). Amusing for a few minutes.
- **[amstradt](https://frenchbloke.github.io/amstradt/amstradt.html)** — Imagine if Amstrad made the shittiest sounding sample / hold / looper. Imagine no more. It's hissy, it's meant to be.
- **[temute](https://frenchbloke.github.io/temute/)** — If Temu made audio software. Takes the idea of locking beat 1, 5, 9, 13 etc of something 4/4, then takes beat 2 and smears it across 2, 3 & 4 etc. Ultimately pointless but it gave me a few ideas at least.
- **[DJMince](https://frenchbloke.github.io/DJMince/)** — Just stupid but proved a point. Import one track, import another. Uses track one (unless you hit shuffle) as the basis for what you hear — beats 1, 5, 9, 13, the doof bit — and uses bits of both 1 & 2 to fill up the gaps. Sounds like a car crash but fun with non-doof doof.
- **[disappointment](https://frenchbloke.github.io/disappointment/)** — Instant (well, once it calculated the time / format shifting to get the original bpm) schaffel and waltzes and 7/8 and chaos.
- **[aspire](https://frenchbloke.github.io/aspire/)** — A synthesised choir triggered when satellites pass overhead. Data is from last week so will lose its reliability.
- **[precentor](https://frenchbloke.github.io/precentor/)** — The first choir related thing I tried. Play using the a–j keys.
- **[orrery](https://frenchbloke.github.io/orrery/Orrery.html)** — Took the choir idea then added the Eno / Koan Pro random generative pattern looping cycle thing. It spins, it sings.

These are all HTML files so you can right-click, save as, and use them wherever you want.
